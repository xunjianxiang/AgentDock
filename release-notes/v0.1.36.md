# AgentDock 0.1.36

## 中文

本版本重建 Skills 的发现、安装和多客户端管理流程，让 AgentDock 可以直接浏览 skills.sh，并通过 skills CLI 管理 project 与 global 作用域。

### 新增功能

- 新增 skills.sh 搜索以及 All-time、Trending、Hot 榜单，支持分页展示、本地缓存和安装前的 Skill 详情查看。
- 使用 skills CLI 检测 project 与 global 作用域中已安装的 Skills，并合并展示来源、安装路径和已启用客户端。
- 新增多客户端安装与启用流程，可管理 `.agents/skills` 共享目录以及 Claude Code、OpenClaw、Hermes 等客户端的独立目录。
- 新增 Skills API 系统代理设置；Windows 可读取当前用户代理配置，也可关闭代理强制直连。
- 移除共享 Skill 时会保留仍由独立客户端使用的副本，避免影响其他客户端。

### Bug 修复

- Skills 写操作现在在后台串行执行，避免安装、卸载或同步阻塞界面，并防止并发操作互相覆盖。
- 改进 skills CLI 启动：从已知搜索路径解析 `npx`，兼容 Windows `.cmd`/`.bat`，增加超时控制并持续读取大量输出。
- 清理命令输出中的 ANSI 控制字符，避免终端样式代码污染错误提示和界面文本。
- 修复卸载 Skill 时丢失原 project/global 作用域、使用错误目录名，以及目标已不存在时仍报告失败的问题。

## English

This release rebuilds Skills discovery, installation, and multi-client management, allowing AgentDock to browse skills.sh and manage project and global scopes through the skills CLI.

### New Features

- Added skills.sh search plus All-time, Trending, and Hot leaderboards with pagination, local caching, and Skill details before installation.
- Installed Skills are now detected through the skills CLI across project and global scopes, with their source, install path, and enabled clients shown together.
- Added multi-client install and enable workflows for the shared `.agents/skills` directory and independent client directories such as Claude Code, OpenClaw, and Hermes.
- Added a Skills API system-proxy setting; Windows can use the current user proxy configuration or force direct access when disabled.
- Removing a shared Skill preserves copies still used by independent clients.

### Bug Fixes

- Skills writes now run serially in the background, preventing install, remove, or sync operations from blocking the UI or overwriting one another.
- Improved skills CLI startup by resolving `npx` from known search paths, supporting Windows `.cmd`/`.bat` shims, enforcing timeouts, and continuously draining large command output.
- ANSI control sequences are removed from command output so terminal formatting does not leak into errors or UI text.
- Fixed Skill removal losing the original project/global scope, targeting the wrong installed directory name, or reporting failure when the target was already absent.
